  <action>
Create EntitlementValidator class with:

1. **Constructor**: Takes optional list of EntitlementRule (immutable config per D-04)

2. **addRule(rule: EntitlementRule)**: Add rule to internal list, return this for chaining (per ENT-05)

3. **removeRule(ruleId: String)**: Remove rule by identifier (per ENT-05)

4. **validate(request: EntitlementRequest): EntitlementResponse** (per ENT-01):
   - Generate UUID requestId
   - Evaluate rules in list order (per D-02)
   - For each rule: check if all EntitlementCondition values match
   - First rule where all conditions match determines decision
   - Collect matchedRuleIds (ID of first matching rule) and evaluatedRuleIds (rules evaluated until the first match)
   - Return EntitlementResponse with decision, reason, rule IDs
   - Add AuditRecord to AuditLog (per ENT-03)

5. **getAuditLog(): AuditLog**: Return reference to audit log

Key evaluation logic (per D-02):
- EntitlementCondition matching:
  - RoleCondition: request.roles.contains(roleName) -> match
  - GroupCondition: request.groups.contains(groupName) -> match
  - CustomAttributeCondition: request.customAttributes[attributeName] == attributeValue -> match
- AND semantics: All conditions in a rule must match for rule to match
- List order: First matching rule wins, stop evaluating after first match
</action>
